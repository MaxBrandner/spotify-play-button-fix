# Spotify userscripts

Small userscripts for the Spotify web player. Each one works on its own, so install only the ones you want.

| Script | What it does |
|---|---|
| [Detach play buttons from the old session](play-button-fix/) | Once Autoplay has taken over, play buttons start their own music again instead of pausing an unrelated song. |
| [Press / to search](slash-search/) | Press `/` to jump to the search field and `Esc` to leave it. |

To use them you need a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/). Details and limitations are in the README of each script.
