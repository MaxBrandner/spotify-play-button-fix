# Spotify userscripts

Small userscripts for the Spotify web player. Each one works on its own, so install only the ones you want.

| Script | What it does | Install |
|---|---|---|
| [Detach play buttons from the old session](play-button-fix/) | Once Autoplay has taken over, play buttons start their own music again instead of pausing an unrelated song. | [Greasy Fork](https://greasyfork.org/en/scripts/604462-spotify-web-detach-play-buttons-from-the-old-session) |
| [Press / to search](slash-search/) | Press `/` to jump to the search field and `Esc` to leave it. | [Greasy Fork](https://greasyfork.org/en/scripts/604554-spotify-web-press-to-search) |

To use them you need a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/). Details and limitations are in the README of each script.
